# Design Tokens
## Sistem Informasi Seminar & Sidang

Design tokens ini digunakan sebagai acuan visual untuk implementasi antarmuka aplikasi mobile Sistem Informasi Seminar & Sidang. Seluruh mockup menggunakan token yang konsisten agar mudah diterjemahkan ke dalam kode.

## 5. Reusable Components

Design system menggunakan reusable components berikut:

1. Primary & Secondary Button
2. Input Field
3. Information Card
4. Status Badge
5. App Bar / Header
6. Bottom Navigation

---

## 6. Implementation Rules

- Semua layar menggunakan color tokens yang sama.
- Spacing mengikuti skala 4, 8, 16, 24, 32, dan 48px.
- Typography menggunakan enam level yang telah ditentukan.
- Button, input, card, badge, app bar, dan bottom navigation menggunakan reusable components.
- Hindari penggunaan warna HEX atau spacing acak di luar design tokens.
- Design tokens menjadi referensi untuk implementasi UI Flutter dan workflow berbantuan AI.
